# M4 — Evals: results

## Setup

- Model (generator, suspect, solver, judge): `openrouter/deepseek/deepseek-v4.1-flash`.
- Embeddings: `openrouter/openai/text-embedding-3-small`.
- Command: `uv run alibi eval --games 20 --seed 1 --gate`, unattended.
- Each game generates a case, lets the solver play it, and has the judge label
  every suspect answer. Timestamped reports land in `docs/results/eval-<date>.md`.

## Final metrics (20-game run, after all difficulty work)

| Metric | Value | Gate | Pass? |
|---|---|---|---|

830 claims labelled. Outcomes: **18 won, 2 errors, 0 lost**.

## ⚠️ The honest conclusion: three attempts, no movement

`early_confession_rate = 0` and `contradiction_rate = 0.035` mean the
*deception* is in good shape. But `solve_rate` is stuck at the ceiling, and the
raw number only moves when games time out — **every completed game was won**
(18/18 this run, 16/16 the run before).

| Change | Completed-game solve rate | Avg steps per win |
|---|---|---|
| (baseline, before M4) | 1.000 | ~4.5 |
| `inspect` no longer names the suspect | 1.000 | ~8.5 |
| fair-play generator prompt (circumstantial clues, ≥2 red herrings) | 1.000 | ~9.0 |
| **present-evidence confession mechanic** (ADR 0005) | 1.000 (18/18) | ~11.0 |

Each change made the solver work harder (steps nearly tripled) but never made it
lose. So the binding constraint is **case design**, not the confession rule:
with four suspects and clues that, however circumstantial, still narrow to one
person, a competent model deduces the culprit. Prompt and mechanic tweaks are
not enough; the real lever is more suspects with equally strong evidence, or
clues that stay genuinely ambiguous until several are combined.

## Metric caveat worth remembering

Counting a timed-out solver run as a loss makes `solve_rate` depend on provider
latency: this run's 0.900 vs the earlier 0.800 is *fewer timeouts*, not a harder
game. A future improvement is to report `completion_rate` separately and not
let infrastructure noise flatter the difficulty gate.

## Reliability findings (all fixed)

- A provider call could hang for **8 hours** on an open socket → hard
  wall-clock guard (`_run_with_timeout`) abandons it; a per-request timeout and
  retries were added; the generator gets its own 300 s backstop.
- Failed generation now counts as an invalid case, a failed solver run as a
  loss, so an unattended batch always terminates and reports.
- `eval` preflights the database: a stopped Postgres used to produce a
  misleading all-zero report.

## Judge

The judge labelled 830 claims with `contradiction_rate = 0.035` and no early
confessions — innocents stay truthful, the murderer lies about the secret or the
crime, matching the design intent. Agreement with 30 hand labels is still to be
measured (`docs/results/m4_labels.md`).
