# M5 — Detector, Web UI and Homelab: results

## Web UI ✅

`uv run alibi web` serves a FastAPI + Jinja + HTMX app (no JS build step):

- index (case list, "Generate a new case", "Start a game");
- the board: actions left, rooms to search, evidence to inspect, one chat box
  per suspect with evidence checkboxes, and an accuse form;
- "What really happened": the true timeline and each suspect's secret.

Every action calls the same `Game` the CLI and MCP server use. Covered by 9
tests (`tests/test_web.py`) and a live smoke test against Postgres + uvicorn.

## Lie detector — export + serving done, training pending ⏳

- **`alibi export-dataset`** exports labelled claims as train/val/test JSONL,
  **split by case** (each eval game is its own case, so no leakage). On the
  claims collected so far: **1,271 statements** (train 985 / val 130 / test 156).
  Aim for ≥ 1,500 by running more eval games.
- **`ml/train.py`** fine-tunes `distilbert-base-uncased`, reports F1 against
  always-TRUE and majority baselines, and exports `model.onnx` + `tokenizer.json`.
  Run it on Colab/Kaggle — `torch` is in the `ml` extra and never ships to the
  server.
- **`detector.py`** loads the ONNX model with ONNX Runtime on CPU and predicts
  TRUE/FALSE. It is wired into the `lie_detector` tool: with no model it says so;
  with a model it returns a fuzzy hint ("the needle trembles"). Covered by unit
  tests with a fake detector; the ONNX path is exercised once a model exists.
- `ml/MODEL_CARD.md` is scaffolded for the training numbers and failure cases.

**Not done here:** the actual fine-tune (no GPU/torch in this environment) and
therefore the "< 100 ms per statement" and "beats always-TRUE" checks.

## Homelab deployment ✅ (mostly)

- `Dockerfile` (python:3.12-slim, no torch) + `compose.homelab.yml` with memory
  limits; verified the image builds and `docker run alibi:test alibi --help`
  works.
- `docs/deploy-homelab.md`: Cloudflare Tunnel, cost caps, backup.
- Spend cap: exceeding the daily budget now shows a friendly message in the web
  UI and the terminal ("The detective is out of budget today") — unit-tested.
